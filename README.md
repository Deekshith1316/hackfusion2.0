# CarePulse AI Demo

A hackathon-ready demo project for an IoT and AI-based remote patient monitoring system.

## Project idea
This system combines connected medical devices, live health telemetry, and AI-driven risk scoring to help caregivers monitor patients remotely. It simulates wearable and home-monitoring data such as heart rate, SpO2, temperature, blood pressure, and activity trends.

## Features
- Real-time patient monitoring dashboard
- AI risk scoring for each patient
- Severity categories: Stable, Watch, Critical
- Smart alerts and treatment recommendations
- IoT-inspired telemetry simulation for healthcare use cases

## Tech stack
- Python
- Flask
- HTML/CSS/JavaScript

## Run locally
1. Open a terminal in the project folder
2. Create and activate a virtual environment
3. Install dependencies
4. Start the app

Example:

```bash
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
python app.py
```

Then open:

http://127.0.0.1:5000

## Demo flow
The app shows multiple patient records with simulated health readings and AI-generated recommendations so judges can see how the product would support clinical decision-making in remote care environments.
